# SnackBot Specification

This spec starts empty on purpose. Its clauses are written round by round, **from the
learner's own accepted answers** during each round's SPEC phase. Nothing in here was
handed down; all of it was argued into existence.

**Legend — the one classification that matters:**
- `[deterministic]` — **code invokes** the operation: every turn, on a schedule, or on a
  predefined condition. Runs regardless of model judgment.
- `[agent-triggered]` — **the model invokes** the operation, via a tool call, at its own
  discretion.
